## 设计与取舍

[T02](T02-列表时间戳.md) 的列表已显示标题和最后修改时间。T03 在操作栏增加系统 `SearchView`，打开后输入即筛选。在 `NotesList` 内组装查询条件，沿用 Activity 收到的 URI、原投影 `_id`、`title`、`modified` 及 `modified DESC` 排序。Provider 已经向 SQLite 转发 `selection` 和 `selectionArgs`，可直接用于本次查询。

## 验证记录

通过 Provider 在实验模拟器准备下列演示数据，保留 T02 的两条英文笔记。使用真实列表和编辑界面操作，用 UIAutomator 核对屏幕标题、搜索词和提示，并通过 Provider 查询确认操作对应的行 ID。

| 标题 | 正文 | 用途 |
| --- | --- | --- |
| 数据库复习 | 游标用于读取查询结果。 | “数据库”只在标题里，“游标”只在正文里 |
| 课程清单 | 本周复习数据库并完成练习。 | “数据库”只在正文里 |
| 字面字符 | `O'Reilly 100% a_b notes\path` | 四种特殊字符的正向样本 |
| 通配对照 | `OReilly 100X aXb notespath` | 检查普通字母不会冒充特殊字符 |
| 长按临时项 | 长按对象检查，等待删除。 | 验证筛选后的改名及删除 |
| 长按对照项 | 长按对象检查，保留对照。 | 与临时项同时命中，核对操作对象 |

| 搜索词或场景 | 应命中或预期 | 实际观察与结论 |
| --- | --- | --- |
| 数据库 | 课程清单、数据库复习 | 两条均命中，按 `modified DESC` 排列，仍显示修改时间。通过。 |
| 游标 | 数据库复习 | 仅“数据库复习”命中，标题不含“游标”。通过。 |
| 找不到的测试词 | 无 | 列表无结果并显示 `No matching notes`。通过。 |
| 依次输入单引号、`%`、`_`、反斜杠，再输入 `notes\path` 和 `O'Reilly` | 每次只命中“字面字符” | 每次均只返回“字面字符”，“通配对照”未命中。通过。 |
| 普通空格夹全角空格，随后重新搜索并点清除 | 两种操作都恢复全量 | 两次均恢复当时的全部 8 条笔记。通过。 |
| 搜“数据库”后点开“课程清单”，删去正文中的“数据库”并保存 | 返回时保留搜索词，只剩“数据库复习” | 打开的正文属于 ID 4。保存返回后仍显示“数据库”，结果只剩“数据库复习”。清空后仍能打开“课程清单”，把原文恢复后重新搜索再次命中两条。通过。 |
| 搜“长按对象检查”后长按“长按临时项”，先改名再删除 | 初始命中“长按对照项”和“长按临时项”，只改动临时项 | ID 5 改为“长按临时改名”并因修改时间更新移到首行。删除后当前结果只剩 ID 6 的“长按对照项”，其余记录均与删除前一致。通过。 |
| 收起搜索后使用原有新建入口 | 恢复全量，用新建按钮打开空编辑器，直接返回后不增加记录 | 收起后显示当时剩余的 7 条笔记。新建空笔记并返回后仍为这 7 条。通过。 |
| 搜“数据库”后旋转屏幕 | 列表重建后保留搜索词和两条结果 | 旋转与复原后，搜索词及“课程清单”“数据库复习”均保持。通过。 |
| 从一个没有笔记的单条 URI 打开列表，再搜“数据库” | 按收到的 URI 查询，结果为空 | 打开 `content://com.google.provider.NotePad/notes/2147483647` 时显示 `No notes yet`，开始搜索后显示 `No matching notes`。恢复常规启动后仍显示原有 7 条笔记。通过。 |

应用包和测试包构建通过。最终在同一模拟器运行原有的 `NotePadProviderTest`（9 项）和 `NotePadActivityTest`（1 项），全部通过。
