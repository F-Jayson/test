# T02 · 列表时间戳

在当前 NotePad 仓库执行 T02。先读 `AGENTS.md`、`docs/项目规划.md` 中的 T02 和已有 T01 记录。完成可从笔记列表观察的“最后修改时间”。

1. 从 `NotePad.Notes.DEFAULT_SORT_ORDER`、Provider 的 `insert`、`NoteEditor.updateNote/onPause` 和 `TitleEditor.onPause` 核对默认值和实际写入路径。沿用现有毫秒值、表结构与排序。
2. 在 `NotesList` 现有投影和适配器映射中加入 `modified`，调整 `noteslist_item.xml`，让标题下显示设备本地日期和时间。保留 `_id` 和长按菜单读取标题的正确列。遇到缺失时间显示占位。
3. 检查并以最小改动保证真正修改正文或标题才推进最后修改时间。保留新建、空笔记退出和撤销行为。用 A、B 两条笔记验证旧数据能显示、修改较早的 A 后移至首行、仅改标题会更新、只打开或撤销不会改变原时间。界面精度不足以区分两次操作时核对原始毫秒值或跨显示时间单位验证。
4. 写 `docs/开发记录/T02-列表时间戳.md`，配修改前后列表或等价的实测证据，说明已有字段和本次差异。更新规划状态，在回复末尾给一条中文 Git 提交信息，由用户自行提交。
