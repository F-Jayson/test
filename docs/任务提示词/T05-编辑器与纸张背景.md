# T05 · 编辑器与纸张背景

在当前 NotePad 仓库执行 T05。读 `AGENTS.md`、`docs/项目规划.md` 中的 T05 和 T04 主题选择。围绕“长文可读、能选背景、重开有效”完善现有编辑器。

1. 从 `note_editor.xml`、`NoteEditor.LinedEditText` 和编辑器菜单入手，调好正文边距、字号、行距和横线对比。提供“白纸／暖纸”两种可辨识的背景，通过编辑器菜单直接选择。用 `SharedPreferences` 保存一个全局选择。
2. 当场切换背景，保留正在输入的文字、光标位置和笔记的修改时间。将选择应用到下一次打开的编辑器。沿用原来的保存、撤销、改标题和删除逻辑。
3. 用有多行中文的样例，在输入法展开时切换、滚动和继续输入。保存重开应用后核对内容与背景。验证未编辑时仅切换外观不会改变列表时间。用同一条笔记截两种背景。
4. 写 `docs/开发记录/T05-编辑器与纸张背景.md`，解释背景值的保存位置、绘制位置与实测结果，更新规划状态。回复末尾给一条中文 Git 提交信息，由用户自行提交。
