# T01 · 原版基线

在当前 NotePad 仓库执行 T01。先读根目录 `AGENTS.md` 和 `docs/项目规划.md` 中的 T01。本任务用于取得后续报告的原版对照，只观察和记录。

1. 对照 `NotePad.Notes`、`NotePadProvider`、`NotesList`、`NoteEditor`、`TitleEditor`，说明一条笔记从创建、改正文或标题，到重新出现在列表的路径。指出列表投影、时间字段、已有纯文本接口和已有测试覆盖的内容，记录与运行观察分开。
2. 在独立实验环境准备两条能在后续复用的非隐私笔记。用 UI 走一遍新增、保存、重开、改标题、撤销和删除，删除只用临时样本。尽可能运行现有 `NotePadProviderTest` 和 `NotePadActivityTest`，记录实际覆盖及结果。设备不可用时保留源码基线，并列出具体未验证项。
3. 保存原版列表与编辑器截图，记下设备、样例标题与可见行为。将记录写入 `docs/开发记录/T01-原版基线.md`，更新规划表。结尾给一条中文 `docs` 类 Git 提交信息，由用户自行提交。
