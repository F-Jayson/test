# T06 · 导出单条笔记

在当前 NotePad 仓库执行 T06。读 `AGENTS.md`、`docs/项目规划.md` 中的 T06。目标是从列表长按一条已保存的笔记，得到可用普通文本查看器打开的 UTF-8 文件。

1. 查看 `NotePadProvider.getStreamTypes/openTypedAssetFile/writeDataToPipe` 及对应测试。长按菜单用选中行 ID 构造笔记 URI，请求已有的 `text/plain` 流。沿用“标题、空行、正文”格式。
2. 用 `ACTION_CREATE_DOCUMENT` 提供文件名并由用户选择目标，用 `ContentResolver` 将源流复制到所选 URI。保存待导出笔记的身份直至选择器返回，正确处理取消、目标不可写和实际复制失败。选用简单的后台读写方式，关闭所有打开的流。
3. 用同名不同正文的两条笔记验证选中的是正确一条，另测中文、多行与取消选择。重新打开导出的文件，核对标题、空行和正文。源笔记保持完整。若某个故障场景无法实测，注明原因。
4. 写 `docs/开发记录/T06-导出单条笔记.md`，保存文本查看器中的运行截图，更新规划表。回复末尾给一条中文 Git 提交信息，由用户自行提交。
