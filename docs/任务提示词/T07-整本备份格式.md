# T07 · 整本备份格式

在当前 NotePad 仓库执行 T07。先读 `AGENTS.md`、`docs/项目规划.md` 中的 T07，核对数据契约和 Provider 返回的时间类型。为接下来的 WebDAV 备份与恢复写一份双方共用的 JSON 读写逻辑。

1. 从笔记集合 URI 查询整本数据，独立于列表当前的筛选结果。用现有平台 JSON API 写 UTF-8，顶层对象包含整数 `version`（1）和数组 `notes`。每条保存 `title`、`note`、`created`、`modified`，两项时间为原始整数毫秒，省略本地 ID 和界面偏好。
2. 实现对同一格式的解析和校验。应能还原中文、换行、引号、空字符串和空集合。损坏、缺字段、错误类型或未知版本要能被调用方辨别，解析过程不得修改数据库。
3. 用少量针对性测试验证编码、再解码后四个字段及条数一致，至少实际验一个错误输入。记录可公开的样本与对照结果，本任务无需为格式新增界面。
4. 写 `docs/开发记录/T07-整本备份格式.md`，记录格式、实现位置与实测边界，更新规划表。在回复末尾给一条中文 Git 提交信息，由用户自行提交。
