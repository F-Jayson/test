# T04 · 列表与主题美化

在当前 NotePad 仓库执行 T04。读 `AGENTS.md`、`docs/项目规划.md` 中的 T04，取得 T01 原版截图和 T03 实际界面。目标是在保留已有操作的前提下，让用户一眼能区分标题、修改时间、搜索和新增入口。

1. 在现有原生 View 和资源上设定一套简洁的浅色主题，统一标题和时间的字号层级、背景、留白与可点击区域。检查 Manifest 中各 Activity 的主题，保留改标题窗口的对话框形态。继续沿用 `ListActivity` 和列表项映射。若自定义列表容器，使用它要求的系统列表 ID。
2. 让空笔记本和搜索无结果分别显示有意义的文案。长标题和较大系统字号下时间仍可读。使用已有菜单承载操作，保留新建、搜索、点击、长按。
3. 用与 T01 尽可能相同的笔记和设备截取改版列表，验证长标题、两种空状态、至少一个原菜单入口，记录实测效果。把前后截图配对，注明哪些变化来自 T02/T03。
4. 写 `docs/开发记录/T04-列表与主题美化.md`，更新规划表。回复末尾给一条中文 Git 提交信息，由用户自行提交。
