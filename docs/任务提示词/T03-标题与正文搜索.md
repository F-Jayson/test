# T03 · 标题与正文搜索

在当前 NotePad 仓库执行 T03。读 `AGENTS.md`、`docs/项目规划.md` 中的 T03 和 T02 的列表改动。目标是一个搜索入口，输入关键字即可找到标题或正文包含它的笔记。

1. 在 `NotesList` 放置一个原生搜索入口。沿用该 Activity 收到的 URI、现有列表投影和排序，通过 Provider 的 `selection`、`selectionArgs` 查询。用参数绑定和必要的 LIKE 转义处理单引号、百分号、下划线及转义符本身。清除或输入全空白时恢复全部。
2. 处理无匹配的提示、反复输入时旧游标的释放，以及从编辑器返回时按当前关键字刷新。点击和长按按结果的真实 ID 打开或操作笔记。
3. 准备标题“数据库复习”、正文含“游标”的笔记，以及只在正文含“数据库”的另一条。实测二者均可命中，另测无结果、清空、特殊字符和筛选后编辑。用独立样本验证长按操作的对象。记录搜索词、应命中和实际命中的标题。
4. 按模板写 `docs/开发记录/T03-标题与正文搜索.md`，保存能说明仅正文命中的运行图，更新规划表。结尾给一条中文 Git 提交信息，由用户自行提交。
