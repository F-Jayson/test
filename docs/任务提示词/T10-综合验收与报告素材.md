# T10 · 综合验收与报告素材

在当前 NotePad 仓库执行 T10。先读 `AGENTS.md`、`docs/项目规划.md` 和 T01 至 T09 的现有记录。这次交付综合验收和报告素材索引。

1. 在实验设备上使用可公开的样例笔记，顺次演示新增与编辑、时间变化、仅正文命中的搜索、背景切换及重开、导出 TXT、整本云备份和从云端恢复。在独立的目标数据上核对恢复总数、正文和原时间。再回归改标题、撤销、复制／粘贴、删除等受影响的原操作。
2. 运行可用的 Provider 与 Activity 设备测试及新增的针对性用例，登记测试名称、设备/API、实际结果与缺口。逐个打开 TXT、云端备份和恢复后的笔记。记录所用 WebDAV 服务，核对 NotePad 上传、云端可见、NotePad 重新下载，以及恢复后的具体数据。
3. 将结果写入 `docs/开发记录/T10-综合验收与报告素材.md`。建立“实验要求、设计／关键源码、实测结论、截图／记录”对应表，复用已有截图，补拍缺图。对遇到的问题链接定位、修复和复测材料。未验证项保留原因。
4. 核对规划表与实际证据一致，每条记录和图片链接可打开。回复中总结两项基础和两组扩展的验收情况，末尾给出与实际改动匹配的一条中文 Git 提交信息，由用户自行提交。
