# T08 · WebDAV 云备份

在当前 NotePad 仓库执行 T08。先读 `AGENTS.md`、`docs/项目规划.md` 的云备份演示方式、T08 任务和 T07 的实际格式。目标是在 NotePad 内手动将整本笔记备份到用户配置的 WebDAV 云盘。默认用坚果云的独立测试目录演示。

1. 在列表菜单加入“云备份与恢复”入口，提供 HTTPS 目录、账号、掩码应用密码和备份按钮。可保留目录与账号，应用密码只在当前会话使用。用平台 HTTPS 客户端、必要的网络权限、后台操作和超时处理，凭据只发给配置的服务。
2. 点击备份时展示条数并说明将替换同目录下的 `notepad-backup.json`，空快照清楚提示 0 条。确认后复用 T07 的全量快照，通过 `PUT` 上传。处理首次创建和后续覆盖的成功响应，以及取消、凭据错误、目录不可用、断网。传输过程中避免重复发起。
3. 在有授权的演示账号、独立文件夹内测试。验证第一次上传和修改后再次备份，检查从搜索结果中发起仍包含全量。用网页端或另一客户端打开远端文件，核对中文、多行、条数与原时间。若尚无账号，使用测试数据验证可执行的路径，并明确真实云端待验。
4. 写 `docs/开发记录/T08-WebDAV云备份.md`，记录配置中哪些是演示前提、请求结果与外部核对结果，配脱敏的应用界面和云端文件截图，更新规划状态。回复末尾给一条中文 Git 提交信息，由用户自行提交。
