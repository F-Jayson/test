# T09 · WebDAV 云恢复

在当前 NotePad 仓库执行 T09。先读 `AGENTS.md`、`docs/项目规划.md` 中的 T09、T07 的实际格式和 T08 的 WebDAV 上传路径。在已有云备份界面增加手动恢复，保留本地笔记，补回缺失副本。

1. 复用 T08 的账号、目录与连接方式，用 HTTPS `GET` 下载同一路径的 `notepad-backup.json`。成功读完后调用 T07 校验，在写库前展示条数与合并规则，请用户确认。处理远端无文件、认证失败、网络中断、无效文件和取消，本地数据应完整。
2. 沿用 Provider 管理 SQLite。在一次事务内按 `title`、`note`、`created`、`modified` 的精确值和出现次数补齐缺项，给新增笔记分配本地 ID，保留原时间。单条写入失败整批回滚。现有默认批量方法如无事务保证，应在 Provider 内补最小的事务入口，成功后刷新观察列表。
3. 仅在独立实验数据上验证。准备备份含 A、B，本地含 B、C。恢复后应有 A、B、C，再恢复同一文件应新增 0 条。另测同名异文、完全相同的两条、损坏文件、未知版本、空备份、取消，以及事务中途失败后的数据完整性。验证 B、C 的本地记录与恢复笔记原时间。
4. 在有授权的云服务上使用 T08 的真实上传结果完成一次往返，记录恢复前后数量、一条样例的四字段和脱敏截图。模拟响应或本地测试单独记录。写 `docs/开发记录/T09-WebDAV云恢复.md`，更新规划状态，回复末尾给一条中文 Git 提交信息，由用户自行提交。
